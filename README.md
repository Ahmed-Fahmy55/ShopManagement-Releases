# برنامج إدارة المحل — نقطة بيع ومخزون

برنامج لإدارة المحلات على جهاز واحد وبدون إنترنت: البيع بالباركود وطباعة الفواتير، المنتجات والمخزون، الموردين وحساباتهم، مصاريف التشغيل، وإحصائيات الأرباح.

## ⬇️ تحميل البرنامج

**[تحميل آخر نسخة — ShopManagement.exe](https://github.com/Ahmed-Fahmy55/ShopManagement-Releases/releases/latest/download/ShopManagement.exe)**

كل النسخ وما الجديد في كل واحدة: [صفحة النسخ](https://github.com/Ahmed-Fahmy55/ShopManagement-Releases/releases)

📘 **الدليل الكامل بالصور:** [ShopManagement-User-Guide.pdf](docs/ShopManagement-User-Guide.pdf)

## 💻 التشغيل لأول مرة

1. البرنامج يحتاج **Windows 10 أو 11 (64-bit)**، ولا يحتاج تثبيت أو برامج إضافية.
2. انقل `ShopManagement.exe` لفولدر ثابت على الجهاز، مثلاً `C:\ShopManagement`، واعمل له اختصار على سطح المكتب.
3. لو ظهرت رسالة ويندوز «Windows protected your PC» اضغط **More info** ثم **Run anyway**.
4. البرنامج يشتغل **7 أيام تجربة مجانية**. للتفعيل: انسخ **كود الجهاز** من شاشة التفعيل (أو الإعدادات ← **الترخيص والأمان**) وابعته للمطوّر، واكتب مفتاح التفعيل اللي يوصلك.
5. ادخل باسم **admin** والرقم السري **1234**، وغيّره فوراً من الإعدادات ← **الترخيص والأمان** ← **رقمك السري**.

## ✨ أهم المميزات

| | |
|---|---|
| 🛒 **نقطة البيع** | البيع بالباركود أو البحث، خصم، كاش أو بطاقة مع حساب الباقي، تعليق واستئناف السلة، واختصارات كيبورد |
| 🧾 **الفواتير** | طباعة على الطابعات الحرارية 58 و 80 مم بالعربي، وإعادة طباعة أي فاتورة |
| 📦 **المنتجات والمخزون** | فئات، فلاتر (مقاس ولون)، باركود وملصقات، توريد، تسوية وجرد، وسجل كامل لحركة كل صنف |
| ⚠️ **نواقص المخزون** | تنبيه بالأصناف اللي وصلت لحد الطلب أو نفدت |
| 🚚 **الموردين** | كشف حساب لكل مورد: المشتريات، المدفوع، والباقي عليه |
| 💸 **المصاريف** | مصاريف التشغيل الشهرية (إيجار، كهرباء، مرتبات) وتتخصم من صافي الربح |
| 📊 **الإحصائيات** | الإيراد، التكلفة، الربح وصافي الربح، الإيراد اليومي، الأكثر مبيعاً، والإيراد حسب الفئة |
| 👤 **المستخدمين** | مدير يرى كل شيء، وعامل يبيع ويرى المنتجات فقط |

## 🔄 التحديثات

- البرنامج **يبحث عن نسخة جديدة وحده** بعد فتحه بثوانٍ، ويعرض ما الجديد فيها.
- عند الضغط على **«حدّث دلوقتي»**: ينزّل التحديث، **يتأكد إنه موقّع من المطوّر**، ياخد نسخة احتياطية من البيانات، ثم يقفل ويفتح بالنسخة الجديدة.
- للبحث يدوياً: الإعدادات ← **الترخيص والأمان** ← **دوّر على تحديثات**.
- بياناتك لا تتأثر بالتحديث.

## 💾 البيانات والنسخ الاحتياطي

- كل البيانات محفوظة على الجهاز في `%LOCALAPPDATA%\ShopManagement` — لا يوجد رفع لأي سيرفر.
- اعمل نسخة احتياطية بشكل دوري من الإعدادات ← **البيانات** ← **نسخ احتياطي الآن**، واحفظها خارج الكمبيوتر.
