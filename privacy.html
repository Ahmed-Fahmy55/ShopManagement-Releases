Privacy Policy

Shop Management · Last updated 19 September 2026

Shop Management is a Windows desktop application for running a retail shop. This policy explains what the application accesses, where that data is kept, and what the developer can and cannot see.

In short: your shop's data stays on your own computer. If you turn on backups, copies go to your own Google Drive. The developer receives no data of any kind and has no access to your files.

1. Data the application stores

All shop data — products, sales, receipts, stock movements, suppliers, customers, expenses and user accounts — is stored in a database file on the computer where the application is installed, under the Windows user's local application data folder. It is never transmitted to the developer.

2. Google Drive backup (optional)

Backing up to Google Drive is off by default. If you enable it and sign in, the application uses the Google Drive API under a single permission scope:

https://www.googleapis.com/auth/drive.file

This scope grants access only to files the application itself creates. The application cannot see, read, list or modify any other file in your Google Drive — not your documents, photos, or anything created by other applications.

3. Your Google sign-in

When you link a Google account, Google issues the application an access token. That token is stored only on your computer, encrypted using the Windows Data Protection API and tied to your Windows user account. It is not transmitted anywhere, and a copy of the file taken to another machine cannot be decrypted.

The application reads your account's email address solely to display which account is linked in its settings screen. This is not stored remotely or shared.

4. Network connections

The application makes outbound network requests in exactly two situations:

  • Google Drive — only when you have enabled backups and linked an account, in order to upload or download your backup files.
  • Update checks — the application queries the public GitHub releases API to see whether a newer version exists. This request contains no shop data. As with any web request, GitHub will see the originating IP address.

There are no other outbound connections.

5. Analytics and tracking

None. The application contains no analytics, telemetry, advertising, tracking or crash-reporting services. No usage information is collected or transmitted.

6. Data sharing

The developer receives no user data and therefore shares none — with anyone, for any purpose, including advertising, training machine-learning models, or sale to third parties.

When you use Google Drive backup, your use of Google's services is governed by Google's Privacy Policy.

7. Your control

  • Disconnect at any time — the settings screen unlinks the Google account and removes the stored token from your computer.
  • Revoke access from Google — visit your Google account permissions and remove Shop Management.
  • Delete your backups — they are ordinary files in your own Drive. Delete them as you would any other file.
  • Delete local data — uninstalling the application and deleting its folder in your local application data removes the database.

8. Children

Shop Management is business software intended for use by shop owners and their staff. It is not directed at children.

9. Changes to this policy

If this policy changes, the revised version will be published at this address with an updated date at the top.
