About (English)

Shop Management is a Windows desktop point-of-sale and inventory application for small retail shops. It handles sales, barcode scanning, receipt printing, stock levels, suppliers, customer credit, expenses and reporting.

All shop data is stored locally on the shop's own computer in a SQLite database. The application works fully offline.

Google Drive backup is optional. When enabled, the application uploads a copy of the shop's own database to the shop owner's own Google Drive account. It requests only the drive.file scope, which grants access solely to files the application itself creates. The developer has no access to any user's files or data.
